Abstract. Rough Set Theory (RST), ﬁrst introduced by Pawlak
in 1982, is an approach for dealing with information systems where
knowledge is uncertain or incomplete.[1] It is of fundamental im-
portance in many subﬁelds of artiﬁcial intelligence and cognitive
science.[2] Given a universe U with an equivalence relation θ, the
pair ⟨U, θ⟩is referred to as an information system and we denote its
collection of rough sets Rθ. In our main Theorem we show Rθ with
|θu| > 1 ∀u ∈U to be isomorphic to core regular double Stone
algebras, CRDSA, that are complete and atomic, and that the
crisp, or deﬁnable, sets form a complete atomistic Boolean algebra.
These guarantees of inﬁmum/supremeum for arbitrary subsets and
formulations in terms of fundamental elements are likely useful if
dealing with equivalence relations with an inﬁnite number of par-
titions, such as projective Hilbert spaces. We further derive that
every CRDSA is isomorphic to a subalgebra of a principal rough
set algebra, Rθ, for some approximation space ⟨U, θ⟩. In our main
Corollary we show explicitly how to embed Rθ into the CRDSA
and ﬁrst demonstrate by extending the culminating ﬁnite example
of [4]. As our capstone, we consider the projective Hilbert space of
complex numbers, C and show, among other things, the power set
of the set of pure states and is a complete, atomistic Boolean al-
gebra. In closing, we suggest other Quantum relevant applications
that may be useful, such as Hilbert spaces of operators.

2. Algebras of Rough Sets
In this section we follow the approach to rough sets followed in [10].
A pair ⟨U, θ⟩that consists of an equivalence relation θ on a nonempty
set U is called an approximation space. Every X ⊆U has an upper
approximation X and a lower approximation X in terms of the θ-
classes. Namely, X = S{θx : θx ∩X ̸= ∅} and X = S{θx : θx ⊆X},
a Rough Set is the pair ⟨X, X⟩. We denote X \ X = BD(X) and
call it the boundary of X. We further note that (X, BD(X), X
c) is
the ternary set partition of U fully determined by ⟨X, X⟩and hence
we can pass interchangeably between the two. From here forward we
will denote (X, BD(X), X

c) since BD(X) is determined by
(X, X

Given ⟨U, θ⟩, we denote the collection of all rough subsets of U by
Rθ. In order to describe the structure placed on Rθ we need a few
deﬁnitions:
Deﬁnition 1. Let P be a lattice with least element 0.
(1) a ∈P is an atom if 0 < a and ∄x ∈P such that 0 < x < a.
(2) P is atomic if ∀b ∈P, ∃a ∈P such that 0 < a ≤b.
(3) P is atomistic if ∀b ∈P, b is the join of a set of atoms.
Deﬁnition 2. A double Stone algebra (DSA) < L, ∧, ∨, ∗, +, 0, 1 > is
an algebra of type < 2, 2, 1, 1, 0, 0 > such that:
(1) < L, ∨, ∧, 0, 1 > is a bounded distributive lattice
(2) x∗is the pseudocomplement of x i.e y ≤x∗↔y ∧x = 0

Now we cite the following Theorems and Deﬁnitions from [6]:
Theorem 1. Let L be a regular double Stone algebra. Then C(L) is
a Boolean sub algebra of L with respect to the induced operations ∧, ∨
and ∗.[6]
Deﬁnition 6. Every element x of a double Stone algebra L with the
property x∗= 0 (or equivalently, x ∗∗= 1) is called dense. Every
element of the form x ∨x∗is dense and we denote the set of all dense
elements of L, D(L). Every element x with the property x+ = 1 (or
equivalently, x++ = 0) is called dually dense. Every element of the
form x ∧x+ is dually dense and we denote the set of all dual dense
elements of L, D(L).
Deﬁnition 7. The core of a double Stone algebra L is deﬁned to
be K(L) = D(L) ∩D(L) and we call a regular double Stone alge-
bra with non-empty core a core regular double Stone algebra, denoted
CRDSA.[6]
For any CRDSA L, |K(L)| = 1 follows easily from regularity and we
will call this element h. We now cite 2 useful results from [6] that we
will use in the next section.
Theorem 2. If A is CRDSA with core element h, then every element
x of A can be written as x = x∗∗∧(x++ ∨h) and x = x++ ∨(x∗∗∧h).
Theorem 3. [6] Two CRDSAs are isomorphic if and only if their
centers are isomorphic.
It is the CRDSA structure that we seek to leverage in further reﬁning

Deﬁnition 11. Projective Hilbert Space
(1) A Hilbert space is a vector space H with an inner product
< x, y > such that H is a complete metric space under the
norm deﬁned by √< x, x >.
(2) The projective Hilbert space P(H) of H is the set of equivalence
classes of non-zero vectors x ∈H∗for the equivalence relation
θ given by xθy ⇐⇒x = cy for some c ∈H∗. It is customary
to choose x with ||x|| = 1 as class representatives for [x].

5.1. Mathematical Results. Given an approximation space ⟨U, θ⟩,
assume that E is the indexing set for the equivalence classes of θ and
let Rθ denote the collection of rough sets of the form ⟨X, X⟩as a regular
double Stone algebr.[10] We give an alternate, simpler, proof from the
one given in [4] of the fact that if |θu| > 1 ∀u ∈U then Rθ is a core
regular double Stone algebra, CRDSA. Further let C3 denote the 3
element chain as a CRDSA and TPU denote the collection of ternary
partitions over the set U. In our main Theorem we show Rθ with |θu| >
1 ∀u ∈U to be isomorphic to TPE and CE

in question are complete and atomic.

regular double Stone algebra is isomorphic to a subalgebra of a principal
