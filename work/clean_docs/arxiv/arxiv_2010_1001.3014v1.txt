1.
Introduction
Lorenz maps are one-dimensional maps with a single singularity, which arise
as Poincar´e return maps for ﬂows on branched manifolds that model the strange
attractors of Lorenz systems. A Lorenz map on the interval I := [0, 1] is a map
f : I →I such that for some critical point c ∈(0, 1) we have
(i) f is continuous and strictly increasing on [0, c) and on (c, 1];
(ii) limx↑c f(x) = 1, limx↓c f(x) = 0.
A Lorenz map f is said to be piecewise linear if it is linear on both intervals [0, c)
and (c, 1]. Such a map is of the form
